# 行简 Windows 桌面版 V2.0

适用于 Windows x64。解压 `CampusFlow-Windows-x64-V2.0.zip` 后，打开 `CampusFlow.exe`。

1. 首次启动默认填写 `http://47.93.112.200:8000`，点击「连接」。可改成兼容的 HTTP 或 HTTPS 服务地址，本地开发可填写 `http://127.0.0.1:8000`。地址可带端口，服务入口应部署在站点根路径。
2. 使用该服务器上的行简账号登录。软件包内置与 Web 同源的界面，课表、任务与会话由填写的服务器提供。服务器需兼容当前行简的 API。
3. 在「连接 → 设置服务器地址」或按 `Ctrl+,` 更换服务器。再次启动会尝试连接上次使用的地址。用「查找功能」或 `Ctrl+K` 可以搜索页面和常用操作。

从旧版升级时，先退出旧版并将新包解压到独立文件夹，再运行新的 `CampusFlow.exe`。如果任务栏曾固定旧版，可取消固定旧图标，从新版窗口重新固定。

Windows 客户端通过现有 Bearer 接口处理登录，勾选保持登录时用 Windows 系统加密存储会话令牌。密码仅用于登录。公网 HTTP 会明文传输登录与业务数据，可在服务端配置 HTTPS 后切换。当前便携包未做代码签名。

桌面工作台包含课表、计划、待办、专注、日周回顾、校园服务、办事指南、助手与历史。Windows 和手机端连接相同服务器并登录同一账号后，可共用账号、课表、计划、待办、在线专注记录、会话和学习偏好。Web 和 Windows 的「设置」提供清新和高级两种配色，主题偏好及回顾笔记保存在当前设备。

- 「今日」将课表、今日待办和学习空档放在一起。展开「找一段学习时间」可以找 25 分钟空档，填入待办草稿并核对后保存。「计划」也可从含明确日期、24 小时时刻及数字时长的标题填入起止时间。
- 在「校园服务 → 校园导航」选择起点和终点。需要确认或更换入口时，在同页搜索并预览候选，点击「确认入口」后即可沿用该入口规划路线。
- 「专注」可以在已登录后选择「仅在本机记录」，恢复联网后手动同步。断线冷启动需先恢复账号登录。本机专注队列按账号和服务器隔离，保留任务编号及计时信息。
- 在「计划」开启后台提醒后，若仍有待提醒项目，关闭窗口时行简留在 Windows 通知区域。通过托盘退出或关闭系统后，提醒停止。
- 「助手」的语音输入使用 Windows 设备当前语言的本机语音识别器，所得文字可修改后加入草稿。缺少识别语言时可使用 `Win+H`。语音朗读依赖 Windows 装有适用的语音。离线历史以 Windows 加密保存，从已连接服务器的登录页进入只读历史。
- 会话名称显示在助手顶部。已保存的会话可在标题旁点击「改名」，也可在「历史会话」里通过该行的「⋯」修改。

## 从源码构建

在仓库的 `desktop-client` 目录执行以下命令，需要 Node.js 22.12 或更新版本和 Windows 的 `tar.exe`。

```powershell
npm ci
npm test
npm run package:windows
```

ZIP 和 SHA-256 校验文件输出到仓库的 `output/windows-desktop/`。本地运行可使用 `npm start`。

桌面软件随包提供界面资源，业务请求与地图服务按服务器地址工作。官方 HDUHelp OAuth 的外部登录流程取决于实际跳转地址和服务器配置。个人访问令牌入口仍在「校园数据」。
