# CampusFlow 分阶段开发与验收计划

每个阶段严格执行以下流程：

1. 完成当前阶段范围内的实现与文档。
2. 运行静态检查、单元测试和必要的端到端测试。
3. 启动可交互版本进行验收。
4. 验收通过后创建独立 Git 提交。
5. 下一阶段从已验收提交开始，避免不同阶段改动混杂。

## 阶段 0：Agent 服务原型

状态：已完成并通过自动化与端到端验收。

- FastAPI Agent 服务与图形化测试台
- DeepSeek V4 Pro / Flash 动态选择
- LangChain/LangGraph 多轮对话
- 课程、天气、通知、地点查询工具
- 事务变更提案、用户确认和演示存储写入
- 早期请求级 API Key 原型（阶段 1.1 已升级为账户级加密凭据）

## 阶段 1：账户与首次配置

状态：已实现并通过自动化、真实视觉和页面端到端验收。

- 注册、登录、退出及会话鉴权
- 学校、校区、学期和基础偏好
- 课表图片/文件导入、解析预览、人工确认
- 校园数据包选择，不要求普通用户上传完整地图
- 首次使用引导和配置完成状态

验收条件：新用户可以完成注册、首次配置、课表确认，并以自己的数据进入 Agent。

### 阶段 1.1：账户设置与管理员控制台

状态：已实现并通过自动化、真实模型与页面端到端验收。

- 注册时添加 API Key，Fernet 加密落库，登录后免重复配置
- 点击头像进入个人配置，可修改昵称、学校、校区、学期和 API Key
- 学习数据页展示课表与地图数据规模和内容样本
- 管理员查看全部注册用户；普通用户不可访问，任何角色均看不到密钥明文

## 阶段 2：App 主框架与历史会话

状态：已实现并通过自动化、真实模型与页面端到端验收。

- 今日、Agent、规划、Skills、我的五个主入口
- 今日课程、待办、提醒和 Agent 建议
- 历史会话列表、搜索、重命名和继续对话
- 会话上下文来源与权限状态展示

验收条件：主要导航可用，历史会话可恢复，核心数据在刷新后仍可访问。

## 阶段 3：规划执行闭环

状态：已实现并通过自动化与页面端到端验收。

- 目标与里程碑拆解
- 计划、待办、日程时间块和提醒
- 课程冲突与地点开放时间检查
- 完成记录、进度统计与阶段复盘

说明：本阶段保存提醒规则；HarmonyOS/Android 系统闹钟与本地通知将在阶段 6 通过 ArkUI-X 系统能力触发。

验收条件：自然语言目标可以转化为经确认后执行的计划、待办和提醒。

## 阶段 4：官方 Skills 库

状态：已实现并通过自动化与页面端到端验收。

- Skill 分类、搜索、详情和版本信息
- 安装、启用、停用、升级和卸载
- 权限声明、安装确认和运行审计
- 首批官方校园 Skills

验收条件：用户可以安全安装 Skill，并明确控制其数据和工具权限。

## 阶段 5：校园数据体系

状态：已实现并通过自动化、桌面端与手机端页面验收。

- 学校/校区版本化数据包（首个数据包：杭州电子科技大学下沙校区）
- HDUHelp iCalendar 课表订阅、加密凭据与手动同步（已完成）
- 建筑别名、地点分类、开放时间、最短步行路径和响应式路线图
- 带有效期与分类的校园通知数据源
- 数据版本、更新来源和用户纠错待审核流程

验收条件：Agent 能基于所选校区稳定查询地点和校园信息。

### 阶段 5.1：HDUHelp Connect 用户档案

状态：PAT 真实账号 Phone 模拟器验收已完成；校园档案展示与数据感知 Agent 推荐已完成；OAuth 流程保留为可选接入方式。

- 用户配置 PAT、Bearer 调用、加密保存和末四位脱敏展示
- OAuth 2.0 Authorization Code + PKCE、一次性 state 和自动刷新
- 身份摘要、学生档案、成绩、考试、校园卡余额和图书馆预约同步
- Token 与资源缓存加密、按用户隔离、断开即清除
- Agent 只读工具、官方 Skill、权限声明和运行审计
- Web 与 ArkUI-X 连接、同步、状态、档案展示、推荐问题和断开入口

验收条件：用户使用 PAT 或官方 OAuth 授权，CampusFlow 不接触校园密码；授权后 Agent 可按实际权限读取同步数据。

## 阶段 6：ArkUI-X 跨端客户端

状态：进行中。已完成共享客户端骨架、核心流程迁移、Phone 模拟器回归和 HarmonyOS HAP 构建；Android APK 与真机签名发布仍待完成。

- ArkUI-X 页面与状态管理（6.1 已完成）
- 登录、注册、首次配置、五入口与 FastAPI 类型化请求层（6.1 已完成）
- DeepSeek 对话、操作确认、课表同步、Skills、规划和原生路线图（6.1 已完成）
- HarmonyOS HAP 构建（已完成）；Android APK 构建（待 Android SDK）
- Agent API、账号、通知和系统能力联调
- 跨端功能与布局一致性测试

验收条件：HarmonyOS 与 Android 可以完成相同的核心用户流程。

## 阶段 7：安全、部署与发布

- 主密钥轮换、细粒度权限审计和生产级密钥托管
- 限流、日志脱敏、异常恢复和备份
- 服务部署、监控和发布文档
- 完整验收与演示脚本

验收条件：通过安全检查、部署演练和核心流程回归测试。
