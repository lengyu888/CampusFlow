# 第十三阶段：可查询和恢复的 Agent 运行

基线：个人仓库 `d1e1b8c`、原项目 `00cc87c`。分支 `feat/stage-13-agent-runtime`，两个 PR 分别基于第十二阶段分支，不修改主分支。

## 使用变化

Agent 每次发送先生成一个 UUID。同一请求的重复提交只读取同一次运行；内容变化则拒绝复用。断网不触发自动重发，页面显示原问题和已收到片段，可查询原运行，也可明确重试同一标识。离开页面暂停本机轮询，服务端可继续执行；返回时读取完整快照。最近 20 次运行提供联网恢复入口，应用重启后也可找到服务端仍保留的结果。

回答来自实际模型文本流，页面约每秒读取增量事件及完整快照。事件重放、乱序或分页缺口不会重复拼接文字。模型推理字段、工具原始参数和凭据不会进入进度事件；工具进度来自真实开始/结束事件，不展示虚构百分比。

取消请求与完成同时发生时以服务端结果为准。取消后不再启动新模型或工具步骤；已生成的待确认提案不等于已执行。超时、预算用尽、取消和服务中断保留未完成片段，只有成功结果原子写入完整问答历史。每条提案绑定所属运行的回答，恢复旧运行不会把新输入偷偷切换到旧会话。

本机历史按完整服务端会话覆盖保存，避免重连多追加一组问答。删除会话会先停止其中的运行，再删除正文和事件；仅保留运行 UUID 与账号的幂等墓碑，阻止迟到重试重新创建被删内容。

## 运行边界

新接口为 `POST /api/v1/agent-runs`，以及按 ID 的 `GET`、`events?after_seq=`、`cancel`；列表支持 `limit=1..50`。记录按账号隔离，成功状态与两条历史消息使用同一 SQLite 事务。

默认整轮上限 90 秒、6 次模型调用、10 次工具调用、24000 字符模型上下文、累计 16000 字符可见输出，单次模型请求最多 4096 输出 token；工具顺序执行，供应商请求不自动重试。`AGENT_TIMEOUT_SECONDS`（不超过600）及 `AGENT_MAX_MODEL_CALLS`、`AGENT_MAX_TOOL_CALLS`、`AGENT_MAX_CONTEXT_CHARS`、`AGENT_MAX_OUTPUT_CHARS`、`AGENT_MAX_TOKENS` 可调。字符预算并不是计费金额或实测 token 成本。

部署使用 **一个 Uvicorn worker**。数据库租约会明确拒绝第二个运行调度进程；没有实现多机任务队列。进程异常退出后，运行在租约到期时转为中断，最长为配置总时长加30秒；正常关闭立即中断。不会自动重跑旧工具。旧 `/chat` 接口保留兼容，新的持久运行、事件恢复与预算合同以 `/agent-runs` 为准。

新运行使用已安装的 OpenAI 兼容 SDK 处理模型流及分片工具参数；工具定义/调用复用现有 LangChain 工具。供应商需要的私有推理续传字段仅在内存中保留。工具返回较长内容时，送入模型的摘录明确标为截取，最终提案和结果仍完整；未额外对原始结果建立数据库容量配额。
