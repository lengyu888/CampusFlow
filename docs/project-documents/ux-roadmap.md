# 行简体验升级：UX01–UX12

本轮延续第十六阶段，不开启原第十七阶段专项。用户已确定中文名「行简」，授权逐阶段完成后上传两个独立分支并继续；各阶段单独审查，不自动合并。个人与原项目的协作文件分别保留。

|阶段|交付|验收核心|
|---|---|---|
|UX01|品牌、三个方向、选定交互原型|同数据比较；窄屏；助手/计划关键状态|
|UX02|原创插图、共享主题、基本组件|统一token、对比度、实际素材、客户端检查|
|UX03|渐进引导和草稿恢复|账号/服务隔离、旧revision不冒充新版本、退出清理|
|UX04|今日快速记录与课程路线衔接|可编辑时间候选、歧义不猜、原ID核对结果|
|UX05|会话边界、解释性提案、语音精修|新/继续会话归属、提案版本、语音不覆盖输入|
|UX06|搜索筛选、紧凑日程、周总览|同名ID、时区、缺时间、重叠、日期上下文|
|UX07|录课/导入、校园入口与设置|重复/重叠不误匹配课程、字段错误定位、真实来源|
|UX08|有限恢复未完成|所有相关写入推进版本、原子幂等回执、并发保护|
|UX09|专注记录|操作状态机、去重计时区间、中断待核对、删除墓碑|
|UX10|事实日周复盘|统计可追溯、不把计划时长当实际投入、不自动重排|
|UX11|全流程与可访问性收口|正常/空/错/未知/离线/大字、真实浏览器原型核验|
|UX12|演示和验收交接|前后对照、赛事逐项证据、两个远端提交和PR|

不安装原生SDK、JDK或模拟器，不进行原生编译、实机验收、真实付费模型评测或线上部署。ArkTS逻辑/静态检查及网页原型不等于三端运行证据；设备与在线链路交给已有环境继续核验。

新增交互始终保留课表版本校验、提案有效期、最新冲突检查、事务提交、幂等回执、账号隔离、可编辑语音草稿、真实来源与已确认提醒快照。
