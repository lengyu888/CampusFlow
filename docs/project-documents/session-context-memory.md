# 同一会话学习约束记忆

本次优化让旧回合被裁剪后，明确表达的部分学习约束仍进入模型输入。
原始聊天历史不变，不新增数据库表、额外模型调用或跨会话事实库。

## 支持的表达

| 约束 | 设置 | 修改 | 撤回 |
| --- | --- | --- | --- |
| 每日时长上限 | 每天最多复习两小时 | 把每天复习上限改成90分钟 | 取消每天复习时长上限 |
| 单次时长上限 | 每次学习不超过50分钟 | 每次学习上限改成40分钟 | 取消单次学习时长限制 |
| 偏好时段 | 以后尽量安排在晚上学习 | 学习时段偏好改成上午 | 取消学习时段偏好 |
| 禁止时段 | 以后不要在晚上安排学习 | 禁止学习的时段改为上午 | 取消学习时段禁用限制 |

“忘记所有学习约束”撤回当前会话的四类约束。后续再次明确设置可以重新生效。
分钟/小时支持阿拉伯数字、常见中文数字、半小时；转换后须为 1–1440 的整数分钟。
时段限上午、下午、晚上；不自动合并多个时段。

这是有限句式识别，不是通用自然语言记忆。引述、代码、条件、问句和带临时日期的表达
不转为稳定约束；“一百五”等歧义数量和多个不一致值标为待澄清，不猜测。
不支持的表达仍可在近期原文中被模型理解，但不能保证在该回合裁剪后保留。
“明天只复习一小时”之类临时要求优先用于本轮，不改变先前的长期范围约束。

围栏按行扫描，记录反引号/波浪线字符及完整开启长度；关闭行须为相同字符、长度不短于开启，
且只允许尾随空白。开启/关闭行允许最多三格缩进，反引号开启行的说明不能再含反引号。
因此四字符围栏中的三字符示例、行内伪关闭及关闭行尾随文字均不能结束资料范围；
未闭合块继续屏蔽到文末，直接引用/列表标记开启的块可在对应容器结束时退出。
屏蔽保留换行及资料占位，避免拼接出用户未表达的约束，合法块外的明确设置仍可生效。
这是有限的资料过滤器，并非完整 Markdown 语法树；间接嵌套列表（如列表后续行才开启围栏）
没有完整的容器追踪，保守屏蔽可能漏提取之后的明确表达，此类表达可单独发送。

## 来源、覆盖与删除

每次请求从后端校验的当前账户/会话冻结历史重建，当前输入最后处理。
资料只包含规范化值、状态和原始历史中的来源序号/时间，不拼入任意原文作为系统指令。
撤回状态会留在本次投影中，提醒模型不能从旧回合重新采用已撤回值。
原始历史重载后依相同事件顺序处理，因此旧值不会跨过撤回重新变成有效值。

投影不写入独立存储：新会话不继承，删除会话仍按既有墓碑与运行取消规则处理。
撤回约束不等于删除聊天原文，也不修改“我的”页面主动保存的学习偏好。
设置页偏好与本会话表达独立，删除设置页偏好不会删除聊天原文；当轮明确要求优先。
课程、任务冲突、截止日期、工具授权及人工确认边界继续生效。

## 上下文预算与验证

系统提示、约束资料、工具 schema、当前回合及工具交互均计入已有字符预算；
近期历史仅按完整问答对保留。必需内容已超限则明确失败，不静默丢弃有效约束。
新运行每步检查；兼容 chat 通过实际 LangChain middleware 在每次模型调用前检查。
旧 chat 的超长工具结果导致明确预算错误；新运行仍沿用已有的显式摘录规则。
兼容 HTTP 聊天接口超限返回 413、`CONTEXT_BUDGET_EXCEEDED`，提示缩小查询范围或新建会话，
不再将本地预算限制归为模型服务故障；失败请求不提交新的问答历史。

离线专项检查实际供应商请求中的资料、旧回合裁剪、撤回和全清、工具续轮、账户/会话隔离、
SQLite 重载，以及真实 LangChain+HTTPX 离线 transport 的兼容入口请求。
测试中的模型回答是离线替身；没有验收真实模型是否遵守约束，也没有证明规划结果质量。
复验命令见 [固定验收基线](agent-evaluation-baseline.md)。
