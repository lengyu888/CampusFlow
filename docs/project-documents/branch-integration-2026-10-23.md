## 整合范围

本次按仓库拥有者要求，将累计功能集中到 `main`。整合基线为 `dev/haohao`（`56ccfb7`）和 `ZMY/agent-improvements`（`cc7f389`），不是逐个复制阶段分支的文件。所有远端阶段分支均是这两个提交的祖先，保留两条历史即可覆盖已有功能；合并后再次逐一验证祖先关系，再删除对应分支。

本地 `docs/contribution-workflow` 的 `c5ef2b6` 经 `git cherry` 确认已在 main 有等价补丁，不重复应用旧文档覆盖新协作规则。仅整理已知分支，不修改其他人的未提交工作。

## 两套前端主题

- 清透 iOS：保留原有冷白、系统蓝与简洁卡片风格。
- 行简纸页：保留米白纸色、松绿和原有校园插图风格。
- 两主题共用业务组件、导航、提案与账号数据，不维护两套不一致的功能代码。
- 切换入口在用户设置；选择在本机持久保存。只更新样式，不退出账号、不清除草稿、不重置导航。
- 系统字号、文字对比与“减少动态效果”行为均保留。

## 整合修复重点

1. 首次配置使用显式、服务端验证的校园预览接口，不依赖尚未保存的个人校区，不放宽普通个人校园服务的范围检查。
2. 会话学习约束不能从列表、引用或代码示例中新增、替换或撤回；保留来源、撤回状态及上下文预算。
3. 日期／时间选择器、错误提示和新建／编辑标签读取响应式状态，不能以编译或 Node 测试代替原生回显验收。
4. 合并兼容修复时同时保留任务恢复、专注和回看类型／API，避免选取一方文件造成静默功能回退。
5. Web 待办完成／恢复改用版本化操作和回执；请求结果不确定时只查询原标识，不盲目重放写入。窄屏会话内也能直接核对并确认提案。
6. Phone 实测发现时间弹窗标题错误地显示 1970 年，已改为课程日期；示例占位文字不视作已填时间，实际选择后再验证重开回显。
7. 规划负荷卡片不再捕获首次加载的空快照；通过实际 Hvigor 回调回归，并在 Phone 验证课程 60 分钟、任务 30 分钟合计 90 分钟，切换空日归零、返回恢复。
8. 专注缓存作用域不匹配时明确说明另一账号保护，禁用开始并提供安全重试；不自动清理、迁移或覆盖旧数据。
9. 主题持久化移至 `loadContent` 成功回调，避免 UI 实例尚未就绪时锁定默认主题；Phone 覆盖安装及再次结束进程后冷启动均保留清透蓝。
10. 专注当前状态与同步详情不再捕获初始快照；真实 Phone 已验证跨重启恢复暂停记录、继续计时、即时暂停、结束和同步，日／周回看读到相同的 3 分 28 秒已确认区间。计时结束不自动标记任务完成。
