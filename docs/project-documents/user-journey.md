# 行简使用指南

日常使用可以沿着这条流程：**准备课表 → 安排待办 → 今日执行 → 按需专注 → 回顾调整**。

## 四个主页面

| 页面 | 在这里做什么 |
| --- | --- |
| 今日 | 看接下来的课程和任务，添加待办，打开任务执行，查看目标进展和今日回顾。 |
| 助手 | 用自然语言查询、拆解目标、生成安排。先看方案，确认后才加入计划。 |
| 计划 | 在日程、目标计划、全部待办之间切换；查看和调整具体任务。 |
| 校园 | 打开课表、校园导航、实时服务、能力管理和个人数据连接。 |

今日页头像进入个人设置。今日页、助手空会话和个人设置都可打开应用内的“使用指南”。

## 第一次使用

1. 注册并登录。在首次配置填写基本资料，至少录入一门真实课程。可订阅导入，也可手动录入。
2. 导入先进入校对流程，检查日期、时间和地点。草稿与账号课表分开，确认保存后才更新账号课表。
3. 模型 API Key、HDUHelp、语音、系统提醒按需配置。手动管理课表与待办不需要模型 API Key。
4. 使用助手前，在个人设置配置模型；在能力管理查看用途和权限，按任务需要安装相关能力。校园个人数据查询需要相应的数据连接。

在 HarmonyOS 登录页勾选“保持登录”后，重开应用会向原服务核验账号并恢复登录；密码不会保存。
服务暂时不可达时，可先“检查连接”，恢复后点“重试恢复登录”。过期或主动退出后需要重新登录。
手动更换服务地址时，返回的登录结果只绑定发起请求的地址，不会沿用到另一个服务。
连接自检也可在“个人设置 → 历史与本机数据”打开；模拟器映射和后端网络需分别核对。

## 安排一天

- 一件具体的事叫“待办”，例如“周一 19:00 复习计算机网络”。有时间的待办进入日程，没指定开始时间的待办留在“待安排”。
- “目标计划”把多项待办和里程碑组织起来，适合一周复习或课程项目。它的进展随具体任务变化。
- 简单事项：今日右上角“＋”添加，选择日期和时间，核对后保存。
- 复杂目标：打开助手描述目标和约束，例如“结合近期课表，安排一周复习，先给我待确认方案”。检查任务、课程重叠和提醒后再确认。
- 返回今日查看接下来的安排；在计划的日程或全部待办中调整日期、内容与地点。发现冲突时，先核对，再确认新的安排。

## 执行任务与专注

打开任务详情，先看时间、地点和当前状态。**做完一件事可以直接标记完成，不必先用专注。**

专注是可选的投入时间记录：

1. 从未完成任务详情选择“开始专注”，或在今日的专注计时区选择任务。
2. 根据需要开始、暂停、继续，最后结束记录。设置目标时长不代表到时自动完成任务。
3. 结束只保存专注记录。任务做完后，另外点击“标记任务完成”；还没做完就保留未完成状态。
4. 本机记录和服务器确认的时间会区分展示。离线或结果未知时，按页面提示同步或核对，避免重复提交。

“完成记录”用于核对完成或恢复操作。恢复未完成不会删除专注记录，也不会恢复旧标题或时间。

## 回顾与下一步

从今日打开“今日回顾”，或从计划进入回顾，按日或周查看：

- 本期已记录且当前仍完成的任务数量。
- 已同步确认的专注时长；未同步记录单独提示。
- 当前没有开始时间的待办数量。

需要时展开统计明细、来源或笔记。笔记可选；使用助手复盘也可选，摘要先填入输入框，由你决定是否发送。

## 校园与设置

- 校园实时服务按教室、图书馆、校园卡、寝室电费等用途查询；数据是否可用取决于连接、权限和上游服务，读取失败会显示具体提示。
- 校园导航先选起点、终点，再生成路线；图上的规划路线需结合当前校园通行情况判断。
- 账号、模型、校园数据连接、学习偏好、提醒和主题在个人设置管理。
- 能力管理控制助手可使用的能力与权限；学习偏好用于安排建议，不会自动开始计时。
- 历史会话用于查看、继续或删除对话，与任务执行记录、专注记录分别管理。
