# 行简：共享界面与交互契约

UX01建立候选与原型，UX02起逐项落实ArkUI-X。旧的 `design-system.md` 保留为第九阶段历史设计，不把历史截图当作本轮原生运行证据。设计选择及浏览器核验记录见 `ux-01-brand-directions.md`。

## 产品与语气

行简是校园事务与学习规划助手。首页先回答下一件事、还有哪些安排、怎样记录新任务；助手把需求转为用户可核对的计划，校园页提供可靠的课表与服务入口。

可见名称用“行简”，四主入口为“今日 / 助手 / 计划 / 校园”。保留内部CampusFlow类型、包标识、存储路径和API，避免无意义改名与数据迁移。简短说明“把事情理清，把计划做成”只在引导/介绍出现。首页不重复宣言。

文案用动作与事实：记一件事、安排这一天、核对结果、恢复未完成。不使用“智能赋能”“一键搞定一切”“专属AI宇宙”等空泛承诺。几条空态：

- 当天没有已知安排：今天还没有安排。可以先记一件事。
- 筛选无结果：没有找到符合条件的事项。可清除筛选查看全部。
- 暂无专注记录：从一项任务开始，记录一次专注。

数据未加载、读取失败、无记录分开说明，不能失败时显示“今天很轻松”。已知一部分数据时明确只代表该范围。

## 三个方向的共同边界

相同数据、相同四主入口、相同真实状态文字，不通过删内容使某个方向看起来更干净。共享中文系统字体，不下载拉丁文展示字体充当中文设计。

- 纸页时间轴：时间是主轴，下一项用短侧线突出，组内轻分隔。默认候选。
- 课程手册：上午/下午/晚上作为章节，任务像目录条目，陶土用于章节重点。
- 一日清单：接下来/今日要做/待安排三段，石墨主色，更多依靠排版与完成标记。

## 纸页方向的语义token

|语义|值|规则|

|canvas|#F6F4EF|页面底色，纯色|
|surface|#FFFEFB|内容组、表单和底栏|
|ink|#29352F|正文、标题、关键时间|
|secondary/muted|#626E65|次级文字，同样要可读|
|accent|#416454|主操作、当前选中、可点击文字|
|accentSoft|#E7EEE6|次操作/选中背景|
|line|#DCE2D8|装饰分隔，不能独自承担可交互边界|
|outline|#788578|输入边界与焦点辅助|
|terracotta|#9B573B|插图局部/极少量点缀，非第二主操作色|
|success/successSoft|#3D7054 / #EDF4EA|有确切回执的成功|

指定不透明色对的计算：正文/表面12.66:1，次级字/表面5.29:1，次级字/底色4.85:1，主色/表面6.56:1，主色/轻背景5.60:1，outline/表面3.84:1。全应用合规不能仅由这些数字推断；实际按压、禁用、透明层需另验。

旧 `blue/actionBlue` 在迁移期映射 `accent`，并引入语义别名给新代码使用。业务语义不是按颜色名替换：错误仍为错误，路线节点、服务状态与任务类型独立核对。

## 字体、空间与组件

布局按vp、字体按fp语义；浏览器CSS px只是近似，不代表原生单位等效。正文16，次级说明13–14，标题26–28，区块标题18–20。正文约1.5行高，允许系统大字增高，不固定高度裁剪。时间用稳定列宽，完整日期和长课程名可换行。

手机内边距16–20；组间24；组内12–16；图标与文字8。内容组圆角16、输入/按钮10–12。按现有48×48 vp最低触区处理，窄屏拥挤时改排列不缩触区。只有一组主操作，不把所有链接铺成全宽实心按钮。

|组件|结构|不可缺失状态/行为|
|---|---|---|
|标题栏|日期或标题 + 头像/至多两个操作|长标题、返回、可访问标签|
|下一项|时间、完整标题、地点、课程/任务语义|已知数据范围、当前项/未来项、重叠提示|
|时间行|固定时间列 + 可换行内容|行详情与勾选分离；当前标记不只靠颜色|
|任务行|完成控制、标题、时间/归属|提交中、失败、未知、真实回执、恢复入口|
|轻表单|可见字段名、可编辑内容、次级选项展开|字段错误定位、草稿保留、保存结果核对|
|助手输入|语音、文本、发送|语音状态、可编辑转写、停止播报、模型不可用|
|提案|目标、日期/时段、任务数、版本关联|待确认、确认中、失效、冲突、未知、已提交|
|来源|标题、原文、资料日期/核对日期|来源范围、读取失败、无命中、非实时声明|
|空态|短说明、适当插图、一个主要入口|空数据与筛选空/失败不混淆|
|底部面板|标题、主体、取消和明确动作|返回保留草稿、错误不清输入、大字可滚动|

主页、输入区与底栏在布局中占位，不能遮住最后一行。键盘出现保持输入可见和近期回答可达；原型键盘占位不证明原生输入法行为。宽屏可限制内容列宽或显示日列表/详情双区，不把手机卡片无限拉宽。

## 三处必要反馈

1. 按压立即有颜色/轻微尺度反馈，约160ms；业务状态不等待动画完成。
2. 展开详情/提案约200ms；内容与触发对象相邻，返回位置明确。
3. 首次出现的主内容轻淡入约180ms，不重复在每次重绘或切tab时播放。

减少动态效果时直接到终态；不循环呼吸、滚动飞入、发光粒子或彩纸庆祝。未知提交结果不能播放成功动画。

## 跨页面交互约定

- 新对话与继续会话必须确认服务端归属；本机历史不可恢复旧提案执行权。
- 从计划进入助手传完整选中日期，先填草稿，不自动发送。
- 课程去路线携带地点/校区；不唯一则选择，不猜位置。
- 无日期/全天事项不进入持续时间条；没有结束就不画虚构高度。
- 今日时间线优先当前/未来安排；明确已结束的课程与已结束且完成的任务可收入“早些时候 · N项”默认折叠组，展开仍完整可达。过时未完成任务归“待处理”，不能悄悄藏进已结束内容；无法确定结束的事项不猜测折叠。
- 筛选无结果保留查询并给清除入口；返回保留滚动和选中日期。
- 编辑草稿带原服务端revision；恢复时版本变化须先对比，不能绑定新revision悄悄覆盖。
- 语音文本先供修改，模型调用和播报均有明确用户动作与可停止入口。
- 已完成/待核对/冲突用文字和形态共同表达，不依赖绿色、橙色、红色。
- 课程重叠允许逐任务设置“可在上课时完成”，默认关闭。具体课程和重叠时段仍提示，经明确确认才显示“已确认课内安排”；不放宽任务互撞、截止日期或版本保护。新重叠重新核对，详见 `ux-course-overlap-policy.md`。

## 插图

UX02使用绘图工具原创七张，母版统一笔触。首轮只有引导、空态与少量快捷入口用图；今日有安排时内容优先。装饰图不读屏，图片按钮仍有文字/动作标签。素材失败只退回文字控件，不遮挡功能。所有正文和按钮文字由UI渲染，不能画进插图。

插图提示词、尺寸、透明性、生成时间、文件校验与实际位置保留清单。不得把生成图当原生界面截图或真实校园场景。

## 检查与实施边界

浏览器原型检查同数据三方向、360/390宽、长标题、大字号近似、键盘占位、提案与未知结果、空/失败和输入草稿。原型每项行为单独对应未来客户端位置，不能用HTML完成代替ArkUI实现。全局主题迁移后执行相关客户端逻辑/静态检查；原生构建与设备验收不在本轮环境执行。
