# 完整计划展示与验收

本次让用户在确认前查看全部里程碑和任务，确认后在规划页按目标找到各阶段任务。保留现有主题、日历及待办操作，服务端生产代码和数据库结构不变。

## 页面变化

- Agent 计划卡片提供展开/收起入口，完整展示任务标题、起止时间、地点、提醒设置和已有冲突提示。
- 重名里程碑和任务分别渲染；预览按提案内位置标识，已确认任务按计划和里程碑 ID 关联。
- 规划页增加“已确认的计划”，可展开目标、里程碑与任务并标记完成；刷新后保留展开状态。
- 空时间、地点、提醒有明确说明，0 分钟提醒显示“任务开始时”。预览、详情与规划日历统一按北京时间显示。
- 展开长计划不会因内容高度变化自动滚到聊天底部。
- 提醒文字描述已保存的设置，不表示系统通知能力已经接通。

## 设备验收步骤

在已有匹配版本的 DevEco/ArkUI-X 环境中，按客户端 README 构建并运行。配置修复命令仅在对应 Windows 开发环境确有需要时执行。

1. 生成一份五里程碑、每个里程碑两项任务的计划提案；包含重复标题和未设置时间/地点/提醒的任务。验收时以接口有效提案为准。
2. 展开完整计划，确认第 5 个里程碑和第 10 个任务可见，逐项核对起止时间、地点、提醒与冲突；长标题可换行，展开后阅读位置不被强制跳到底部。
3. 取消该提案，核对规划没有新增。再生成有效提案并确认，核对“已确认的计划”中的 5 个里程碑与 10 个任务及其归属。
4. 在计划详情中完成一个任务，核对完成数量更新且展开状态保留；原日历、全部待办和删除操作仍正常。
5. 检查空计划/空里程碑的说明；有未归入有效里程碑的任务时，仍能在该计划下看到。
6. 使用 UTC 跨日时间，例如 `2030-10-01T18:00:00Z`，详情和日历均应显示北京时间 `2030-10-02 02:00`；手动全天任务仍显示“全天”。
7. 在目标手机检查较大字号、长计划和展开按钮，记录系统、设备、构建版本及实际截图。各端未执行的项目保持“未执行”。

已知服务端的修改/删除提案执行、失败时部分写入和确认时重检冲突问题另由后端任务处理。本次展示改进和正常创建/取消契约测试，不能代替这些异常场景的修复验收。
