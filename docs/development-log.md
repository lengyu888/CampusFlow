# 开发日志

## 2026-10-05：HDUHelp Connect 用户档案

- 接入 HDUHelp OAuth 2.0 Authorization Code + PKCE，用户在官方授权页登录，CampusFlow 不收集或保存统一身份认证密码。
- 首批同步身份摘要、学生档案、成绩、考试、校园卡余额和图书馆预约；单项失败不会阻断其他资源更新。
- Access Token、Refresh Token 与同步资源均使用 Fernet 加密落库，OAuth state 一次性消费并设置十分钟有效期。
- Agent 新增个人档案、学业和校园生活三个只读工具，并将其纳入“提案—确认—执行”的权限与审计体系。
- Web 与 ArkUI-X“学习数据”页增加连接、同步、状态查看和断开入口；断开时尝试撤销远端令牌并删除本地同步缓存。
- 自动化覆盖 PKCE、授权回调、令牌刷新、部分同步失败、密文缓存、工具读取与断开流程；完成 Web 真浏览器回归及 ArkUI-X HAP 构建。

## 2026-10-05：原始杭电地图路线叠加

- 将用户确认的 HDUHELP 杭电地图原图作为 ArkUI-X 内置地图底图，保留原始建筑、道路和文字信息。
- 校园数据包升级至 `2026.10.4`，路线坐标重新标定到原图主校区画布。
- 根据原图道路重新校准“六教北侧入口—校内环路—南二门/北二门通道—生活区西侧道路—菜鸟驿站入口”，禁止使用建筑中心点之间的直线连线。
- 地图组件改为“原始位图底层 + Canvas 路线层”，路线可独立更新而不修改原图像素。
- 路线卡片明确标注原图来源和 CampusFlow 叠加层，便于区分资料来源与导航计算结果。

- 修复 HarmonyOS NetStack 对空请求体 POST 的兼容问题，注销会真实撤销服务端会话，课表手动同步与操作确认也使用稳定的空 JSON 请求体。

## 2026-10-04：校园步行路线图

- 校园数据包升级至 `2026.10.2`，新增菜鸟驿站、北二门/南二门通道及相邻步行关系。
- 增加基于地点别名的最短路径计算，支持“六教”“菜鸟”等自然简称，并返回预计时间、距离、途经节点和地图坐标。
- Agent 新增 `plan_campus_route` 工具和本地路线意图分流；校园地点助手 Skill 升级到 `1.2.0`，即使模型网络不可用，明确的“从 A 到 B”请求也能直接生成路线图并记录审计。
- 前端根据用户已确认的杭电地图关系绘制响应式矢量导视图，包含动态路线、开放状态和分步指引。
- 提供“六教 → 菜鸟驿站”快速场景，并完成桌面端与 390×844 手机端真实浏览器验收。

## 2026-10-04：校园数据包、通知与用户纠错

- 建立独立的 SQLite 校园数据层，首个版本化数据包覆盖杭州电子科技大学下沙校区。
- 内置 15 个高频地点及其别名、分类、开放时间和关键步行关系，地点工具支持按当前位置返回预计步行时间。
- 增加带分类、有效期和来源说明的校园通知查询，过期通知可在服务端过滤。
- Agent 地点查询合并官方数据包与用户已确认地图数据，保留个人数据优先级并去除重复结果。
- 学习数据页增加数据包版本、指标、通知预览和社区纠错入口；纠错按用户隔离并进入待审核队列，不直接修改正式数据。
- 新增校园数据快照、地点、通知与纠错 API，并完成桌面端及 390×844 手机端浏览器回归。

## 2026-10-04：HDUHelp 课表订阅
