## 2026-10-03：账户凭据、用户设置与管理员控制台

- 注册表单增加 DeepSeek API Key，服务端使用 Fernet 加密保存；生产环境强制配置独立 `APP_SECRET_KEY`。
- 图片解析与 Agent 对话从当前登录账户读取密钥，登录后不再重复填写。
- 点击用户头像进入配置中心，可修改个人信息和轮换 API Key，并查看课表与校园地点。
- 首个账户自动成为管理员；管理员可查看所有注册用户，普通用户接口与页面双重隔离。
- 管理员总览只显示凭据配置状态，不返回密钥明文或尾号。
