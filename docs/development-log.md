# 开发日志

## 2026-10-04：校园数据包、通知与用户纠错

- 建立独立的 SQLite 校园数据层，首个版本化数据包覆盖杭州电子科技大学下沙校区。
- 内置 15 个高频地点及其别名、分类、开放时间和关键步行关系，地点工具支持按当前位置返回预计步行时间。
- 增加带分类、有效期和来源说明的校园通知查询，过期通知可在服务端过滤。
- Agent 地点查询合并官方数据包与用户已确认地图数据，保留个人数据优先级并去除重复结果。
- 学习数据页增加数据包版本、指标、通知预览和社区纠错入口；纠错按用户隔离并进入待审核队列，不直接修改正式数据。
- 新增校园数据快照、地点、通知与纠错 API，并完成桌面端及 390×844 手机端浏览器回归。

## 2026-10-04：HDUHelp 课表订阅

- 增加 HDUHelp iCalendar 订阅预览、连接、手动同步和断开接口。
- 解析 Asia/Shanghai 课程事件，支持折行与转义文本、去重、排序和教师字段提取。
- 订阅 URL 仅允许 HDUHelp 官方 HTTPS 域名与固定路径，禁止重定向以避免 SSRF。
- token 随完整 URL 使用 Fernet 加密保存；客户端和状态接口只展示域名、事件数与同步时间。
- 首次配置和“学习数据”页均可连接订阅；断开订阅时保留最近一次已导入课程。

## 2026-10-03：账户凭据、用户设置与管理员控制台

- 注册表单增加 DeepSeek API Key，服务端使用 Fernet 加密保存；生产环境强制配置独立 `APP_SECRET_KEY`。
- 图片解析与 Agent 对话从当前登录账户读取密钥，登录后不再重复填写。
