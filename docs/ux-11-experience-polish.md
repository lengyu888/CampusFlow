# UX11｜完整流程与体验收口

这一阶段不换视觉方向。继续使用纸白底、墨绿动作和少量陶土色，把已完成的页面连成一条可以核对的使用过程，并修复实际暴露的问题。

## 可感知的变化

- **完成后继续做事。** 普通标记完成成功后保留当前页面，底部给出可点击的保存结果。恢复未完成仍先看预览；失败或结果未知保留完整核对入口。主动返回、换页面或打开另一条专注后，旧响应不会抢回屏幕。
- **名称和结果先出现。** 完成／恢复列表优先使用本次操作的任务名称；任务及回执编号可主动展开，所有操作仍按原编号执行。服务回执与当前任务快照继续区分。
- **专注只留一个主读数。** 当前记录从重复列表中排除，本机核实时长与已同步时长分别标注，不相加。已同步的完整区间按需展开；未知操作、缺口、删除、分页和任务完成入口仍可访问。下一次开始表单按需打开。
- **回看时间更易读。** 资料读取时间采用校园时间的自然日期；精确时间与快照编号保留在依据里。普通提示使用中性或成功色，需要处理的异常仍有明确文字与警告色。
- **新账号可以完成首次配置。** 连续旅程发现旧校区数据接口要求已保存个人资料，但首次引导恰好要先读它。新增鉴权只读的 `GET /api/v1/onboarding/campus-data?school=…&campus=…`，仅返回匹配校区的公共资料；不提前保存个人信息，不返回其他账号纠错记录。原 `/campus-data` 的已保存校区限制保留。

## 真正串起来检查

`arkui-x-client/scripts/ux11-journey.mjs` 加载实际 ArkTS 非渲染方法、HTTP 适配器与控制器，经 stdin/stdout JSONL 调同一进程中的 FastAPI 和临时 SQLite。真实产生的任务、提案、运行、回执和计时记录编号在后续步骤继续沿用。文件存储逻辑使用实际生产驱动加 Node 文件系统适配，不能据此认定原生文件 API 已通过。

模型供应商被明确替换为离线脚本流，真实运行与工具流程继续执行；订阅只用固定合成资料和测试传输；没有外网抓取、真实模型、真实通知或原生语音。报告区分模拟边界和实际经过的代码。

运行方式（已有后端测试依赖的环境）：

```sh
cd arkui-x-client
npm test
npm run check
CAMPUSFLOW_TEST_PYTHON=/path/to/backend-test-python npm run test:journey
python3 scripts/audit-ux11-source.py
```

`test:journey` 与纯 Node 单元检查分开；Python 可显式指定，也可使用 `agent-service/.venv/bin/python` 或系统 Python。缺依赖时明确失败，不自动安装或将未执行计为成功。执行结果见 `evidence/ux-11-checks.json` 及其旅程记录。

## 可访问性与素材

`evidence/ux-11-accessibility-audit.json` 保存实际源文件摘要、十组主要文字配色的对比度计算、装饰图读屏排除与失败回退、文字操作路径、减少动态效果、键盘调整及触区源码核对。月历在窄屏保持七列各至少48 vp，允许横向查看；日程列表仍是默认入口。

原创插图共7张，源资源总计10,701,122字节；本阶段没有新增装饰图或重复加入媒体。Web近似演示的文件体积与加载测量单列于浏览器记录，仅描述本次桌面浏览器，不能推导原生启动、内存或帧率。

浏览器检查覆盖手机宽度、大字近似、横屏、键盘占位、减少动态效果以及正常／未知／失败状态。原生字体缩放、读屏焦点与播报、安全区、系统键盘、真实触区和设备性能仍须在队友现有环境验收。
