# UX02｜纸页主题、中文品牌与原创插图

2026-10-18。本阶段把 UX01 选定方向接入实际 ArkUI-X 页面：四主入口与登录、引导、历史、课表、路线、能力和个人设置统一纸白、墨绿与状态语义；用户可见品牌改为“行简”，助手入口使用普通对话图形。内部类名、API、包标识、存储、通知归属与旧历史保持。

## 用户能得到什么

- 下一项用细侧线突出，普通文字和边界更清楚；底栏选中态同时有字重与浅色底，并允许大字增高。
- 信息、加载、空数据、警告、错误、成功和未知写入结果分开。未知结果保持核对原操作路径，不以改版为由允许重发。
- 引导、真实空日程与课表/路线入口使用同一套原创插图；图片失败仍有文字与结构图标可操作。没有在每条任务旁堆装饰。
- 主按钮、表单、提示、时间行和公共容器共享 token。旧颜色名暂留别名，避免遗漏页面出现另一套颜色。

`AppTheme`包含主/次操作、警告、错误、焦点、按压与禁用色。正文16、辅助13、标题28，容器16圆角、控件12。原生Button默认交互反馈继续保留；新增按压/focus色对已在浏览器规范中展示，未据此声称所有原生平台状态完全等效。

七张插图由内置绘图工具逐张生成，合计10,701,122字节。文件、提示、修订、alpha和SHA见 [插图记录](xingjian-illustrations.md) 与 [机器清单](xingjian-illustrations.json)。A1/2/3/5已接入；A4/6/7为UX09–10备图。

[浏览器验收页](previews/ux-02-foundation.html)直接引用项目PNG并映射当前主题。`check-ux-02.cjs`读取真实AppTheme，核对23个CSS颜色及旧别名，计算13组有效状态色对，记录禁用色对；10项浏览器检查通过，0页面错误，0外部请求。真实截图和报告位于`previews/evidence/ux-02/`。

主代理与独立审查实际查看：七图在纸白/表面背景上的40/48缩图、首步引导、今日空态、校园两入口及360宽大字近似。已生成图没有文字残影，入口仍可辨认；没有整页横向溢出。图片失败的网页演示保留全部文字路径。

客户端`npm test`：594项，593通过、1跳过（现有JDK不可用），0失败。`npm run check`：58个ArkTS/TS与17个配置检查通过。最后显示图标/启动底色微调后，34项相关三端源码契约/提醒测试通过，SVG、Android XML与Storyboard可解析。测试中的三处旧品牌文字断言与产品文字同步，原校验未移除。

## 证据边界

以上是客户端逻辑提取、源码/资源契约和浏览器近似。未安装原生环境，未运行原生编译或设备验收，未测试真实语音/提醒送达。跨平台安装后图标、系统大字、键盘、原生图片失败事件和读屏仍交设备核验。网页原型中的保存/回执是标明边界的内存演示；应用业务方法及确认保护未重构。
