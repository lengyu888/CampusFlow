# 第五阶段：核心页面质感与内容层级

本阶段基于第四阶段 `f9f5b03637c41f40ea21c87a12a4d70a43b6164e`，在独立分支 `feat/core-page-polish` 继续。只调整首页、Agent、规划页及其共用样式，不改后端接口。

## 具体作用

| 页面 | 改动 | 使用价值 |
| --- | --- | --- |
| 首页 | 课程、待办前置；原大幅引导卡收为简短入口；统一行距、分隔、圆角、按钮；错误时提供重试 | 打开后先看到需要做的事，少滚动；加载失败不会误显示“没有事项” |
| Agent | 缩小欢迎区；建议使用可点击的原生按钮；回答、工具记录和提案分层；本机保存成功提示移入输入区 | 更容易开始提问、阅读结果和找到确认操作，常规提示减少干扰 |
| 规划 | 选中日期的安排置顶；月历与新增待办表单默认收起；收起表单保留草稿 | 查看日程更直接，需要录入时再展开；输入内容和日期不会因折叠丢失 |

三个页面采用新增的 `AppTheme` 样式常量：20vp 页面边距、24vp 区块间距、16vp 卡片内边距、20vp 卡片圆角、14vp 控件圆角及更深的操作蓝色。原有样式常量保留，其他页面未随本轮重新设计。

顺带修正 Agent 的一个现有显示问题：删除会话后第一次发送仅有一条用户消息，旧判断会把它误认成欢迎页。现在依据是否存在非欢迎消息决定显示对话；发送、确认与本机缓存的业务流程保持原有语义。

## 改前 / 改后查看

直接在浏览器打开 [单文件对照页](previews/stage-5-core-pages.html)，无需安装依赖或运行后端。顶部可切换首页、Agent、规划；Agent 可切换欢迎页和回答/提案场景。规划可体验月历、表单收起/展开以及草稿保留。

**证据边界：对照页是按 ArkUI-X 代码手工实现的浏览器近似预览，非 ArkUI-X 编译产物、模拟器或真机截图。** 改前对应第四阶段代码结构，两侧使用同一组示例课程和待办。字体度量、键盘、安全区、系统控件与原生渲染可能不同。示例操作仅在当前页面生效，不调用模型、后端或真实账户。

## 验证

- `node --test scripts/test-*.mjs`：104 项通过，其中新增 2 项 Agent 消息显示回归、8 项规划折叠/草稿/请求参数回归。
- `npm run check`：29 个 ArkTS/TS 文件、17 个配置文件通过工程静态检查。此脚本检查导入、配置、接口引用等，不是 ArkTS 编译器。
- `git diff --check`：通过。
- 独立代码复核：发送/删除互锁、未知结果只查询状态、完整提案/里程碑、日期选择与两步删除语义保留。
- 浏览器预览：检查三页改前/改后；实际点选建议填入、示例发送、提案展开、表单编辑/收起保留草稿；375px 浏览器视口下三页均未发现横向溢出，首页另检查 812×375 横向视口。预览控制台无错误。以上仅是 HTML 预览证据。

按本轮用户要求，未安装 SDK、模拟器或原生工具链，未做原生构建或实机测试。PR 保持 Draft，由负责原生环境的同学完成三端构建、键盘遮挡、大字体及真实数据验证。
