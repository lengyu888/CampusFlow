# UX01｜行简视觉方向与浏览器验收

2026-10-18，基于第十六阶段。此阶段完成可操作设计原型与实施契约；生产 ArkUI 迁移从 UX02 开始。未安装原生环境，也没有原生编译、设备或真实模型验收。

## 选定：纸页时间轴

三方向使用相同的 2026-10-19 14:10 合成数据：八条定时安排、一条全天事项、一条无日期待办，包含长标题和课表重叠。它们有不同布局：纸页按时间轴，手册按上午/下午/晚间章节，清单按接下来/今日任务/待安排。

实际查看 390 与 360 宽并完成点击后，选择纸页：下一项的时间、地点和到达入口集中；课程与任务能放入同一时间结构；左侧稳定时间列有利于快速扫描。手册多层章节拖长首屏，清单弱化课程在一天中的位置，故未选为全局方案。三方向保留供回看。

曾发现纸页过去课程占用首屏，已调整：明确结束的课程和结束且完成的任务折叠到“早些时候”，未完成旧任务留在“待处理”；未设置结束的事项不推断其已经结束。

配色使用纸白 #F6F4EF、墨绿 #416454、近白表面和少量陶土点缀。普通事项以行和细分隔组织，冲突保留警告区，主要记录入口固定且有文字。完整 token、语气、触区和组件规则见 [共享契约](ux-design-contract.md)，参考产品真实观察及现有源码映射见 [参考记录](ux-01-reference-notes.md)。

## 原型与实际检查

打开 [独立原型](previews/ux-01-xingjian.html)。页面顶部标明“设计原型·合成数据·非原生截图”；不连接账号或服务，全部演示状态刷新即重置。

使用现有 Chrome 和 Playwright 运行 `docs/previews/check-ux-01.cjs`，24 项检查通过，页面错误 0、外部请求 0。检查报告和截图位于 `docs/previews/evidence/ux-01/`。在装有对应工具的环境指定 `PLAYWRIGHT_MODULE` 和 `CHROME_EXECUTABLE` 后运行：

```sh
node docs/previews/check-ux-01.cjs docs/previews/ux-01-xingjian.html ./ux01-evidence
```

覆盖：三方向同数据、过去事项分组、长标题、任务详情和完成分离、快速记事取消保留、真实日期计数、完整月历、搜索空结果恢复、提案确认、未知结果仅查证、课内安排取消和二次确认、任务互撞不得绕过、语音进入可编辑草稿、会话切换以及 320/360/390 宽、大字和键盘占位。

主代理实际查看三方向、展开后的长标题、三项完整提案、360 宽大字键盘未知状态和课内确认面板。页面没有整页横向溢出；原型输入区保持可达。长内容需在手机区域滚动查看，未用截断隐藏。

## 最新课内任务规则

“可在上课时完成”默认关闭。开启后仍展示具体日期、课程和重叠时段，用户明确选择“仍这样安排”才保留，并持续标注“已确认课内安排”。取消不修改，许可不放行任务之间的冲突。这是 UX01 的页面演示；真实字段、候选摘要确认、课表变更重核与助手权限限制在 UX04–UX06 落实，详见 [课内任务策略](ux-course-overlap-policy.md)。
